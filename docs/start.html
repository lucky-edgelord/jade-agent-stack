Quick start

Install, connect, check, then build a site or run a playbook.

Jade Agent Stack is one Python package, jade-agent-stack, that drives the four Jade repositories through their documented interfaces. It is a client and needs the network to reach them.

RepositoryRoleThe toolkit uses
Jade Vaultcontrol plane: agent loop, schedules, approvals, the personHTTP API /v1 (header auth)
Jade Agent Baseresource plane: identity, database, model gateway, billing, audit logREST /api/agent/tools, MCP /api/agent/mcp
Jade Agent Kitthe embeddable subset of Vault (an agent in any web page)a generated page that loads it
Jade Agent UI/UXpresentation: web componentsgenerated HTML that loads them

Install

pip install jade-agent-stack          # Python 3.11+; needs only PyYAML
pip install "jade-agent-stack[keyring]"   # store tokens in the OS keyring

Connect

jade init                 # seven steps; resumable; --yes for defaults, --answers FILE for headless
jade doctor               # reachable, authenticated, compatible, no tokens in URLs

jade init writes jade.config.yaml (found later by walking up from the working directory, or $JADE_CONFIG). Tokens go to the OS keyring under jade.<host>, never into the file.

Build a site

jade site new "Acme AI" --template saas --tagline "Embeddings for every app."
jade site build           # → dist/ (static files)
jade site preview         # http://127.0.0.1:8080
jade site plan            # every Base call a deploy makes; makes none
jade site deploy          # collections, modules, models, plans, billing, then the files

Run a playbook

jade playbook check examples/base-products.playbook.yaml
jade playbook plan examples/base-products.playbook.yaml
jade playbook approve base-products
jade playbook run base-products --var collection=products

Find help

jade docs topics
jade docs search "idempotency key"
jade docs show playbooks#failure-modes
jade commands               # every command with its parameters, as data
