Live demos

Everything below runs in your browser from the CDN, at the commits this toolkit pins, in Jade's Vault look. python3 build/demos.py builds them with the toolkit's own commands (jade vn build --cdn, jade edu validate), and python3 build/demoshots.py plays each one in headless Chrome and fails on any error.

Sites

Each site below is built by jade site build from a few lines of jade.site.yaml (in examples/sites/<name>/), in the default jade theme. Sites that need a backend show their pages, and their forms and sign-in work once deployed to a Jade Agent Base.
