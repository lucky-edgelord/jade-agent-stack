Architecture

The five parts, who owns what, and the contract between Vault and Base.

Vault asks. Base answers. Base logs. Base can say no.

PartOwnsDoes not
Jade Vaultthe agent loop, schedules, heartbeat, autonomy, budgets, approvals, the user-facing transcriptbecome a server for others
Jade Agent Baseidentity, the database, the model gateway, billing, the authoritative audit loghost an agent, schedule anything
Jade Agent Kitthe embeddable subset of Vault: the agent in any web pageown data or identity
Jade Agent UI/UXweb components and themestalk to anything but Kit and Base
jade-vn-enginegames: Ren'Py-style scripts on MicroPython, effects, maps, battles, tours, Live2D (lazy ES modules)own data, talk to Base
jade-educourses: course JSON, the player with a talking teacher, labs (lazy ES modules)own data, talk to Base
Jade Agent Stacka client over all of them: SDK, CLI, wizard, harness, playbooks, sites, games, courses, docscopy their logic

Every front-end (Kit, UI/UX, the engine, edu) is an ES module loaded from a pinned CDN path that finds its own files with import.meta.url and imports the rest on first use; all of them read UI/UX's --jade-* tokens.

The seam between Vault (or Kit) and Base is MCP (/api/agent/mcp), with the same tools over REST. Fleet (many terminals sharing one vault) is users, not distributed compute.

The contract, in short

TopicRule
TranscriptVault owns what the person sees
AuditBase's agent_audit is authoritative, including refusals
Credentialsone short-lived task credential per task, least privilege, at most 24 h; revocation fails closed
Refusal403 credential_refused or a scope error: stop and tell the person; do not retry
Idempotencyevery mutation has a key; Base runs it once and replays the answer for 24 h
Resumea run's state says which tasks finished; running again skips them
Phone sleeps mid-flowthe credential may expire; the run resumes with a new one and the same keys
ApprovalsVault owns the model; the toolkit enforces its own copy locally (deny wins)

The full text is CONTRACT.md in the repository.
